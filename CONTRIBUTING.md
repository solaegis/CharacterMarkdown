# Contributing to CharacterMarkdown

Thank you for your interest in contributing. This project is released under the [MIT License](LICENSE).

## License

By contributing, you agree that your contributions are licensed under the MIT License. Include the copyright notice and permission notice in substantial portions of the Software as required by MIT.

## Pull requests preferred

- Prefer opening a pull request against this repository rather than publishing a renamed fork on ESOUI.
- Forking on GitHub does **not** by itself grant permission to release the addon as your own listing on esoui.com.
- If you want to maintain or take over the ESOUI listing, contact the author and request team membership with ESOUI admins (see [docs/ESOUI_BEST_PRACTICES.md](docs/ESOUI_BEST_PRACTICES.md) §§5–6).

## Credits and reuse

- Credit any code, concepts, assets, or information derived from other addons, developers, or external resources (including when found via AI-assisted research).
- Read and honor third-party licenses before copying or adapting code. If a license forbids reuse, do not work around it.
- Do not remove or replace author credits.

## Patches and language packs

- Ask the author before publishing a separate language patch or optional patch addon.
- If creating an optional patch on ESOUI, name it with the original addon name first (for example `CharacterMarkdown Updated <DLC>`).

## Policy and security reports

- Report bugs and feature requests via [GitHub Issues](https://github.com/solaegis/CharacterMarkdown/issues).
- Do not spam the ESOUI forums with repeated removal or takeover requests; follow the moderator PM process in the best-practices doc.

## Development

See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) and [docs/ESOUI_COMPLIANCE.md](docs/ESOUI_COMPLIANCE.md). Before proposing release-related changes, run:

```bash
task validate:esoui
task test
```
